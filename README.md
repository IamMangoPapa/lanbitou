## ✨ 功能特性

- 📝 **图文混排**：支持在笔记内容中任意位置插入图片（粘贴或上传），富文本编辑体验
- 🔒 **用户加密**：登录用户笔记内容自动使用 AES-GCM 加密，标题、标签等元数据明文以便搜索
- 👤 **独立用户管理**：注册、登录、登出一键完成，用户数据隔离
- 🏷️ **智能标签系统**：预设常用标签，支持自定义添加，每个标签自动分配不同颜色
- 🔍 **多维度筛选**：按公开/私密筛选，按标签多选筛选，关键词搜索
- 👁️ **预览模式**：点击卡片标题或预览按钮，全屏查看完整内容，并可直接跳转编辑
- 📁 **本地目录同步**：选择存储目录后，所有更改自动同步到 `data_用户名.json`，关闭页面自动保存
- 📦 **数据导入导出**：一键导出为 ZIP 包（含数据 JSON），支持导入恢复
- 🎨 **深色/浅色主题**：跟随系统或手动切换，护眼舒适
- 📱 **响应式设计**：完美适配桌面、平板、手机
- 🖼️ **图片灯箱**：点击笔记中的图片可放大查看

---

## 🛠️ 技术栈

- **纯前端**：HTML5 + CSS3 + JavaScript (ES6+)
- **加密**：Web Crypto API (AES-GCM, PBKDF2)
- **存储**：localStorage + File System Access API (目录同步)
- **压缩/解压**：JSZip + FileSaver.js
- **图标**：Font Awesome 6
- **无第三方框架**，轻量、快速、安全

## 🚀 快速开始

### 环境要求
- 现代浏览器（Chrome 86+, Edge 86+, Firefox 90+, Safari 16+）
- HTTP/HTTPS 协议（File System Access API 需要安全上下文）

### 本地运行

1. **克隆或下载**本仓库到本地
2. 使用任意 HTTP 服务器启动：
   ```bash
   # 方法1：VS Code Live Server (推荐)
   右键 index.html → Open with Live Server

   # 方法2：Python
   python -m http.server 8000

   # 方法3：Node.js
   npx http-server -p 8000
   ```
3. 打开浏览器访问 `http://localhost:8000`

### 部署到 GitHub Pages

1. 将仓库推送到 GitHub
2. 在仓库设置中启用 Pages（分支 `main`，根目录）
3. 访问 `https://你的用户名.github.io/仓库名`

## 📖 使用指南

### 首次使用
1. **注册账号**：点击顶部用户图标 → 输入用户名和密码 → 点击“注册”
2. **设置存储目录**（可选）：点击设置图标 → 选择目录（建议 `D:\lanbitou`），程序会自动创建 `lanbitou` 子目录
3. **开始记录**：点击右下角 `+` 按钮

### 笔记管理
- **添加笔记**：填写标题、内容（支持图文混排）、选择可见性（公开/私密）、添加标签
- **编辑笔记**：点击卡片上的编辑按钮
- **预览笔记**：点击卡片标题或预览按钮
- **删除笔记**：点击卡片上的删除按钮（确认弹窗定位在按钮旁）
- **批量操作**：点击多选模式按钮，勾选多个卡片，底部栏批量删除

### 标签使用
- **快速添加**：在编辑器标签区域，点击已有标签自动添加到当前笔记
- **自定义标签**：输入新标签名，点击 `+` 按钮即可
- **筛选标签**：在筛选栏点击标签（可多选），页面位置不动，只过滤内容

### 数据安全
- 登录用户的内容使用密码派生的 AES-GCM 密钥加密
- 密码仅保存在 sessionStorage，关闭浏览器即清除
- 未登录用户数据保存在公共空间（明文，仅供临时使用）

## 🔐 加密原理

- 用户密码通过 PBKDF2 派生密钥（100,000 次迭代，SHA-256）
- 笔记内容使用 AES-GCM 加密，每条笔记独立盐值和 IV
- 加密后存储于 localStorage，同时同步到目录文件
- 解密在内存中进行，不持久化明文
